# Ściąga programistyczna

Aplikacja jest zrobiona w React, Node.js i SQLite. Służy do zapisywania własnych notatek z programowania.

## Uruchomienie

Wpisz:

```text
npm install
```

```text
npm run dev
```

To uruchomi React i serwer Node. Otwórz `http://localhost:5173`.

Baza danych tworzy się sama jako plik `notatki.db` po uruchomieniu serwera Node.js.

## Build

```text
npm run build
set NODE_ENV=production
npm start
```
